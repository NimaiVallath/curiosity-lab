# Curiosity Lab

> Tiny experiments for when “what if?” is reason enough.

This is a collection of playful, intuitive coding projects. Each one should make
sense within a few seconds, invite interaction, and reveal an interesting rule
underneath the surface. The point is not to imitate a product—it is to follow a
curiosity all the way to a finished little thing.

![Keyboard Constellations turning a phrase into a night sky](projects/001-keyboard-constellations/examples/make-room-for-wonder.svg)

## The experiments

| # | Project | The invitation | Built with |
|---:|---|---|---|
| 001 | [Keyboard Constellations](projects/001-keyboard-constellations) | Type a thought and watch it become a repeatable night sky | JavaScript, Canvas, deterministic systems |

## What belongs here

- An interaction you can understand without a tutorial.
- A small rule that produces a surprising result.
- Tiny AI and agent ideas whose reasoning can be watched, tested, and questioned.
- A visible artifact, not just implementation notes.
- Enough engineering care that the fun survives edge cases.
- No accounts, ads, trackers, paid APIs, or manufactured productivity claims.

## Run the checks

```bash
node scripts/check.mjs
```

Every experiment runs locally and uses focused automated tests. AI assistance is
part of the workshop; the ideas, taste, review, and decision to keep an experiment
remain human-owned.
